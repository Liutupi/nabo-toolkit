# 宿主契约测试

从仓库根运行 `./tools/validate.sh --static`。依赖 Node.js、Python 3、C11 宿主编译器；精灵解码测试不需要 Pillow/NumPy 或 ESP-IDF。

- 18 项 Node 测试：纯 JS 规则、开机/语音/跳过时间、配对码与取消、右侧修饰键、相机连拍节奏、PPT 计时、唤醒、VM 内真实内联 DOM 按键接线，并捕获三项故意修改的规则。
- 7 项 C 探路测试：4,000 次输入与 JS 按键分类器逐项比较、uint32 计时回绕、认证/订阅就绪条件全组合、键盘/多媒体精确字节、断线行为、导航及配对码前导零/取消。
- 8 项精灵测试：已知 RLE/差分行、损坏/截断、边界/调色板/时间/CRC，以及正式包逐帧解码和预算。
- 7 项刷写保护测试：app 哈希/芯片/大小、精确分区及 MD5、标记、安全状态、Flash 容量、实测旧表和更小的 app 边界；测试不打开串口。
- `verify_golden.py` 在临时目录重录 1,559 步，对三个文件逐字节及 SHA256 比较。覆盖 10 个页面、6 种按键、5 种连接事件和 4 个 OS；`hid_tables.json` 导出原始表与解析后默认值，不改作者键位。

F0 没有实现完整 C 应用模型。JS 基准及 C 按键差分测试不等于完整 JS–C 状态对拍，也不代表硬件兼容性。真机验收见 `../docs/VALIDATION.zh_CN.md`。
