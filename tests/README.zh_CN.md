# 宿主契约测试

从仓库根运行 `./tools/validate.sh --static` 或 Windows 原生 `./tools/validate.ps1 -Static`。依赖 Node.js、Python 3、C11 宿主编译器；精灵解码测试不需要 Pillow/NumPy 或 ESP-IDF。

- 29项Node测试：纯JS规则、开机/语音/跳过时间、配对码与取消、右侧修饰键、相机连拍节奏、PPT计时、唤醒、FIFO替换与新配对时拒绝旧设备回连、VM内真实内联DOM按键接线，以及配置schema/客户端/生产C协议通信；捕获三项故意修改的规则。新增检查六组顺序、截图Esc、四OS无修饰↑/→/↓、编辑Cmd/Ctrl+Z/C/A，以及 `withDefaultGroups` 保留cards且不修改输入。
- 7 项 C 探路测试：4,000 次输入与 JS 按键分类器逐项比较、uint32 计时回绕、认证/订阅就绪条件全组合、键盘/多媒体精确字节、断线行为、导航及配对码前导零/取消。
- 8 项精灵测试：已知 RLE/差分行、损坏/截断、边界/调色板/时间/CRC，以及正式包逐帧解码和预算。
- 7 项刷写保护测试：app 哈希/芯片/大小、精确分区及 MD5、标记、安全状态、Flash 容量、实测旧表和更小的 app 边界；测试不打开串口。
- 4 项 F0 采集器测试：嵌入日志行的状态解析、隐私字段白名单、排除模拟/未连接内存，以及不把广播计时当成全程重启计时。另有 2 项可选数字比较实验检查：只接受实体短 OK/长上拒绝，拒绝过期/取消/零令牌；1 项回连策略检查覆盖 500/10000 ms 边界及 uint32 回绕。Windows 下 C 库在清理临时目录前显式卸载；宿主策略通过不代表真机回连已达三秒。
- `verify_golden.py`在临时目录重录1,710步，对三个文件逐字节及SHA256比较。包括原1,582步和128步自定义配置；覆盖10页、6键、5种连接事件和4 OS。默认HID表按用户明确要求更新为截图、Typeless、剪映、微信读书、抖音、编辑；C导出与当前JS表同步，旧截图/粘贴、Typeless和剪映的保留动作不变。

本轮新默认组的完整门禁**PASS：102项（29 Node+73 Python）、1,710步完整对拍、3项故意变异被捕获，ESP-IDF6.0.2/F3构建通过**。候选 `0.3.1-shortcuts-dev1` 尚未刷入或发布。既有F3 dev3曾通过100项；F2阶段为87项（27 Node+60 Python）。生产JS客户端经stdio连接生产C协议/解析/存储代码，宿主套件不开真实串口。

新版默认组按钮的保留范围是当前页面cards；更新旧设备须先读回，再替换groups，最后显式写入并核对。schema测试证明函数不修改输入、保留名片和拒绝坏配置，不代表浏览器权限流程或物理App行为通过。旧dev3实际USB写入/3次读回属于单独设备配置核验，见[配置说明](../docs/CONFIGURATION.zh_CN.md)；本轮没有刷固件或擦NVS。

`test_tk_model.py` 使用实际生产 C 模型，逐步比较全部1,710步的完整JSON状态、全部输出及sleepDue，含可变组数/名片数、平台空绑定、64字符文字宏、媒体键、缩减索引；三项故意C变异被抓到。轨迹适配器只转换配置ABI，JSON解析/持久化/客户端另由F2端到端测试验证。演示设备只在宿主注入，生产初始化无假绑定。

F3另检查92帧动画的原索引像素/时间/查找/循环/边界/CRC、压紧字库与原字库的等价性、PCM逐样本播放/取消/回放及5ms提示音包络。渲染器使用真实字体/LVGL头，检查十页/弹窗、六位宽数字、QR内容切换、自定义中文备用字形、欢迎阶段与工具动画，逐像素比较脏刷新与全刷新。新版组名/标签已重新生成所需字形，但不以宿主字形存在证明真机可读性。

完整 `validate.ps1 -Stage F3` 或POSIX `validate.sh --f3` 先reconfigure取得锁定LVGL/cJSON再测；F2回归仍可用 `-Stage F2` / `--f2`。静态模式缺LVGL时显式SKIP，不能算通过；缺cJSON则明确失败。IDF6不支持MSYS构建。C预览另需Pillow：`python tools/render_toolkit_preview.py --f3`。

NVS/NimBLE测试用RAM提供器注入写入/提交失败、合成地址和旧偏好，核验先提交后淘汰、失败保留、F0迁移和暂存清理；不证明RTOS并发或真实Flash断电安全。真机验收见[验证记录](../docs/VALIDATION.zh_CN.md)。完整编译、宿主通过不等于手机/电脑App实际响应通过。用户已确认旧dev3配置更新后的当前测试端能调出截图并能取消，微信读书/抖音反馈“可以了”；测试端未注明手机还是电脑，因此不代表各平台或具体跳章/快进行为逐项通过，也不代表未刷候选的设备验收。
