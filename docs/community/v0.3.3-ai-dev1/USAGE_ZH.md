1. 安装与配对
社区固件为完整安装，会替换现有程序和分区布局，并可能重置配置、配对和个人模板；需要保留资料时，请先查阅项目发布说明中的保护升级方法。右侧按键从上到下为上、下、OK。开机后上下选择，OK 进入，长按上键返回。

在「连接」中选择配对新设备，在电脑或手机蓝牙设置中选择「NABO 工具箱」，按屏幕提示完成配对，选对设备类型。最多保存三台设备，一次连接一台。

2. 呼出 AI 助手并语音输入
电脑安装 Codex、Claude、Grok Bot 和 Typeless，按项目中的电脑桥接说明启动桥接，并配置 Typeless 自己的快捷键：
https://github.com/Liutupi/nabo-toolkit/blob/main/desktop-bridge/README.zh_CN.md
Mac 需要辅助功能授权；Windows 桥接仍待实测。桥接运行时进入工牌「快捷键」的「AI助手」组，上键、下键、OK 分别呼出 Codex、Claude、Grok Bot。确认聊天输入框有光标。

亮屏时长按 OK 切到下一组 Typeless，短按 OK 触发你已配置的 Typeless 语音输入；录完后长按下键返回 AI助手 组。息屏时长按 OK 先亮屏，需要再长按一次才能切组。助手界面和输入框焦点受应用版本与系统权限影响；未自动聚焦时请手动点击。

3. 已有配置的用户
升级不会自动替换已保存的快捷键组。用电脑 Chrome/Edge 打开 https://liutupi.github.io/nabo-toolkit/，USB 连接工牌，先「从工牌读回」，再选择「加入 AI 助手快捷键组」，检查其他组与名片后明确写入并核对。最多六组；已满需自行调整。浏览器保存只保存页面草稿。

4. 其他工具
PPT 上下翻页、OK 黑屏；会议组提供摄像头、举手和静音快捷键；媒体先选音乐或抖音；拍照需打开支持音量键快门的手机相机；名片上下切换、OK 放大。具体行为取决于目标应用和焦点。

主菜单长按 OK 进入离线语音查找，选择读书、抖音、音乐、名片、拍照、截图或语音输入；每词长按 OK 录入三次，短按 OK 识别。识别只进入工具，不自动执行动作。样本保存在工牌本地，个人短口令识别并非通用听写。
