1. Install and pair
The community firmware is a full installation: it replaces the existing application and partition layout and may reset settings, pairings and personal voice templates. To keep existing data, read the project's protected upgrade instructions first. The three right-side buttons are UP, DOWN and OK from top to bottom. Use UP/DOWN to select, OK to enter, and hold UP to return.

Choose Pair new device under Connection, select NABO 工具箱 in the computer or phone Bluetooth settings, follow the pairing prompts and select the correct device type. Up to three hosts can be saved; one connects at a time.

2. Open an AI assistant and dictate
Install Codex, Claude, Grok Bot and Typeless on the computer. Start the NABO desktop bridge and configure your own Typeless shortcut:
https://github.com/Liutupi/nabo-toolkit/blob/main/desktop-bridge/README.md
The Mac bridge needs Accessibility permission. The Windows bridge has not yet been physically tested. With the bridge running, open Shortcuts and select the AI assistant group. UP opens Codex, DOWN opens Claude, and OK opens Grok Bot. Confirm the chat composer has focus.

While the badge is lit, hold OK to move to the next group, Typeless, then briefly press OK to trigger your configured Typeless dictation shortcut. After dictating, hold DOWN to return to the AI assistant group. If the display is dark, the first long OK only wakes it; hold again to change groups. App versions and system permissions can affect focus; click the composer manually if needed.

3. Existing configurations
An upgrade does not automatically replace saved shortcut groups. Open https://liutupi.github.io/nabo-toolkit/ in desktop Chrome or Edge, connect the badge by USB, read its configuration, choose the button to add the AI assistant group, inspect the other groups and cards, and explicitly write and verify. Six groups are allowed; adjust existing groups yourself if full. Browser Save only saves the local draft.

4. Other tools
PPT turns slides with UP/DOWN and toggles black screen with OK; meeting shortcuts control camera, hand and mute; Media offers Music or Douyin; Camera requires a phone app with volume-key shutter; Cards switches QR cards with UP/DOWN and zooms with OK. Results depend on the target app and focus.

Hold OK in the main menu for offline voice search. Choose reading, Douyin, music, cards, camera, screenshot or voice input; hold OK to enroll three examples per phrase, then briefly press OK to recognize. Recognition only opens the tool. Acoustic examples stay on the badge; this is personal short-command matching, not general dictation.
