二、认清实体键并配对
正面朝向自己，右侧从上到下是上、下、OK，OK在最下方。屏幕和本版配置页也依此排列。
1. 等约5.5秒欢迎结束或按任意键跳过；菜单上/下选、OK进入。
2. 进“连接”，选择“配对新设备”，按OK打开窗口。宿主蓝牙选择“NABO 工具箱”，按双方提示输入或比较数字，需要双边确认时核对一致后两边都确认。
3. 选真实设备类型Mac、Windows、iPhone/iPad或安卓；顶部就绪再用。一次只连接一台，先断开占用NABO的其他宿主。最多3份绑定，新配对成功替换最早绑定，不必清空NVS。

三、工具操作（以下按上、下、OK实体顺序）
通用长按约0.5秒，松手不补短按；长上返回。媒体活动页先回媒体选择，再长上回菜单；二维码放大时先退出放大。
• 快捷键：上/下/OK执行当前组，亮屏长OK下一组、长下上一组。默认五组：截图＝截屏/Esc/粘贴；Typeless＝翻译/随便问/语音输入；剪映＝分割/撤销/播放暂停；微信读书＝↑/↓/→；编辑＝撤销/全选/复制。Typeless需电脑已有软件与对应绑定。读书→是否跳章由App、模式和焦点决定。旧个人六组兼容，不自动删组。
• PPT：上页/下页/黑屏恢复；长OK开始、长下结束。时间与页数只是本地记录。
• 会议：摄像头/举手/静音切换；长OK换模板，仅电脑端，应用快捷键须匹配。
• 媒体：先上/下选音乐或抖音，OK进入不发键。音乐＝音量+/音量−/播放暂停，亮屏长OK下一曲、长下上一曲。抖音＝↑/↓/→，长OK/长下无工具动作，右方向键可能快进，不承诺下一视频。
• 拍照：先打开支持音量键拍照的手机相机；上切0/3/10秒、下五连拍、OK拍摄/取消倒数，实际成片以手机为准。
• 名片：上/下换卡、OK放大/收起二维码。

四、息屏时怎么操作
“设置→息屏遥控”默认开。只在已连接、无配对/设备类型弹窗的快捷键或媒体活动页起效；从进入/亮屏起30秒息屏，短键不重置计时，菜单/媒体选择保持亮屏。
暗屏短上/下/OK照常发当前动作。长OK只亮屏并消费此次动作，不顺带换组/切歌；松手不补短OK。亮屏后重新给30秒，亮屏原长OK功能保留。长上亮暗均返回并亮屏。关闭开关则遥控保持亮屏；它与自动深睡不同。
开关独立保存在remote_v1，不迁移/擦除settings_v1、cfg_v1或绑定；本版真实断电保留与功耗仍待测。

五、电脑配置快捷键和名片
https://liutupi.github.io/nabo-toolkit/
本版离线页也在Release内，完整解压后打开config.html。使用与本版对应的配置页；既有公开旧包保留原内容，不自动随固件升级。
1. 电脑Chrome/Edge、USB数据线；关闭串口监视器。连接工牌并选择正确USB口，先“从工牌读回”。开串口可能重启，需要时重连。
2. 每组按上/下/OK显示，仍最多6组；Mac/iPhone与Windows/安卓分别录键。系统拦截的组合键用“手动”；文字宏最多64个ASCII字符/换行。
3. 要换新版五组且保留设备实际名片，先读回，再点“使用新版默认快捷键（保留名片）”。按钮只改当前页面groups，不自动写工牌，不自动删除旧保存的抖音组。确认草稿后显式写入核对。
4. 顶部“名片 / Wi-Fi 二维码”编辑1–3卡；二维码最多160个UTF-8字节。生成Wi-Fi码后手机扫码入网，工牌不联网，密码在二维码/导出中为明文。
5. “写入工牌并核对”成功且读回一致才是保存成功；“保存到浏览器”只存本机。传输中断先重连读回，勿盲写。导出含密码时不要公开分享。
