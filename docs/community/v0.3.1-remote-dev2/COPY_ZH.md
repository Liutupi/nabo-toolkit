NABO 工具箱 · 随身蓝牙遥控器
v0.3.1-remote-dev2 更新：媒体里选音乐/抖音，阅读时息屏继续翻页。

把AI Passport变成离线蓝牙HID遥控器，用右侧从上到下的“上、下、OK”三颗键，处理演讲、会议、音乐、短视频、拍照和二维码。沿用原七条NABO动画、完整欢迎、专用开机语音与按键音，不重新制作素材。

【六大工具】

1. 快捷键｜常用动作一按发送
默认五组：截图、Typeless、剪映、微信读书、编辑。截图组上键截屏、下键Esc取消、OK粘贴；微信读书上/下发↑/↓，OK发→，具体翻页/跳章由App与阅读模式决定。Typeless、剪映保留作者原绑定；编辑组上撤销、下全选、OK复制。网页可改1–6组，每组3键，支持左右修饰键、多媒体键和最多64个ASCII字符/换行的文字宏。Mac/iPhone与Windows/安卓分别设置。Typeless只触发电脑现有软件，工牌不录音。旧个人六组不会被自动覆盖或删除。

2. PPT｜翻页笔与本地演讲计时
上/下翻页，OK黑屏/恢复，长OK开始放映，长下结束；显示本地计时和翻页计数，不读取电脑真实页码。实际快捷键需与PPT/Keynote及系统匹配。

3. 会议｜静音、摄像头、举手
上摄像头、下举手、OK静音切换；长OK切换腾讯会议、飞书、Zoom、Teams模板。仅电脑端，缺少对应快捷键时会提示。HID只发送，不知道会议的真实状态。

4. 媒体｜先选音乐或抖音
上/下选择、OK进入，进入动作不发HID。音乐保留上/下音量、OK播放/暂停、亮屏长OK下一曲、长下上一曲。抖音上/下/OK发↑/↓/→，长OK/长下无工具动作；→可能快进，不保证下一视频。长上从活动页回媒体选择，再长上回菜单。

5. 拍照｜延时快门和五连拍
先打开支持音量键拍照的手机相机。上切换0/3/10秒，OK拍摄或取消倒计时，下五连拍。通过“音量+”触发快门，计数不确认照片已保存。

6. 名片｜随身二维码
保存1–3张，修改标题、名字、说明和二维码；上/下换卡、OK放大/收起。支持网址、文字、网页生成的Wi-Fi码；每张最多160个UTF-8字节。手机扫码加入网络，工牌不联网；密码在二维码和配置导出中为明文。

【30秒息屏，按键继续遥控】
设置“息屏遥控”默认开。已连接的快捷键/媒体活动页从进入或亮屏起30秒息屏，普通短键不续亮屏计时，暗屏短上/下/OK仍发送。暗屏长OK只亮屏并消费，不顺带换组、切歌或发短OK；亮屏长OK仍执行原工具动作。长上无论亮暗都返回并亮屏。菜单、媒体选择等页面保持亮屏。息屏暂停绘制/动画/LCD传输，保持BLE/按键/USB运行，区别于深睡；不宣称实测节省比例。

【配置页与连接】
https://liutupi.github.io/nabo-toolkit/
电脑Chrome/Edge + USB数据线：连接 → 从工牌读回 → 编辑 → 写入工牌并核对。想换成新版默认组且保留实际名片，务必先读回，再点“使用新版默认快捷键（保留名片）”，最后显式写入。只保存到浏览器不改工牌。离线配置页随本版Release提供；不要公开含Wi-Fi密码的导出文件。
最多3份蓝牙绑定、一次连接一台，新配对成功替换最早绑定；设备类型可选Mac、Windows、iPhone/iPad、安卓。设置另有按键音、开机语音、演讲时长、自动休眠。欢迎约5.5秒进菜单，任意键可跳过。

【已验收与未测】
ESP-IDF6.0.2、ESP32-C3、8MiB、无PSRAM。127项宿主测试、2,206步JS–C对拍和3项故意变异通过。固定app已获授权app-only刷写、校验、复位；配置迁移仅移除匹配的旧抖音组，其余组/名片保留，自动及连续3次读回一致。
用户确认本轮媒体选择/实体顺序、息屏、暗屏翻页、长OK只亮屏通过，耳机/键盘本轮正常。独立暗屏补采在screen_off=true全程完成16条HID/32次notification TX，动画帧9冻结、相关错误0，用户复测“都正常”；TX完成不等于宿主ACK。此前间歇蓝牙连接原因仍未确定，不能称已修复或全平台共存通过。
功耗/续航、remote_v1冷启动保留、全部App/系统矩阵、三槽压力、长稳、完整首装仍待测；历史三秒回连门槛未通过，阅读器/电视未验收。

【安装前必读】
社区安装用完整镜像从0x0写入，会替换默认分区表、重置NVS/设置/蓝牙绑定。固定完整镜像含同一app并通过布局/内容校验，完整首装路径仍未真机验收。要保留现有分区/数据/素材，请使用Release的app-only保护升级，先核对设备、容量、分区并备份，勿用完整镜像代替保留数据升级。
