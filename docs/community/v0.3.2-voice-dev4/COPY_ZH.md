v0.3.2-voice-dev4｜公开实验测试版

让 NABO 陪你翻书、看视频、放音乐、讲 PPT、开会、拍照和分享名片。这次加入本人离线语音查找：先各录三次“读书、抖音、音乐、名片、拍照、截图、语音输入”，以后在语音页短按 OK，说一个已录入词，就能进入对应工具。识别只负责导航，进入后再按原键操作，不会自动截图、拍照、播放或发送快捷键。

语音查找由主菜单长按底部 OK 打开；不持续监听、不联网、不上传原始录音。个人声学模板只留在本机，公开固件不含作者样例，其他人需自己录入。它是本人短口令的模板匹配，不是通用语音转文字、自由对话或身份验证。“语音输入”进入 Typeless/语音输入分组，电脑上的软件仍需自行安装并匹配快捷键。

原来的六大工具继续保留：
1. 快捷键：默认截图、Typeless、剪映、微信读书、编辑五组。截图为上键截图、下键 Esc 取消、OK 粘贴；微信读书发送上/下/右方向键，实际翻页或章节行为由应用决定。可配置 1–6 组，每组三个动作，支持组合键、媒体键和最多 64 个 ASCII 字符/换行；Mac/iPhone 与 Windows/Android 分开设置。旧个人配置不会自动覆盖。
2. PPT：上一页、下一页、黑屏切换；长 OK 开始，长下结束，附本地计时和页数。
3. 会议：摄像头、举手、静音；切换腾讯会议、飞书、Zoom、Teams 模板，需与电脑应用快捷键匹配。
4. 媒体：先选音乐或抖音。音乐控制音量、播放暂停和切歌；抖音发送上/下/右方向键，右键在某些界面可能快进，应用及焦点需自行核对。
5. 拍照：使用兼容音量键快门的手机相机，支持 0/3/10 秒和五连拍；是否实际存图需看手机。
6. 名片：1–3 张二维码，支持网址、文本和 Wi-Fi 内容，上下切换、OK 放大。Wi-Fi 二维码供手机扫码联网，工牌本身不连接 Wi-Fi；密码会包含在二维码和配置导出里。

完整欢迎动画、开机语音、按键音及各工具动画沿用原素材。右侧实体键从上到下是“上、下、OK”，OK 在最底部。快捷键/媒体工具连接后可在 30 秒息屏，短键继续遥控；暗屏长 OK 只亮屏，不附带工具动作；长上返回并亮屏。设置可关闭息屏遥控，不承诺未经测量的省电比例。

配置页：https://liutupi.github.io/nabo-toolkit/
桌面 Chrome/Edge + USB：先读工牌配置，再编辑快捷键/名片，明确写入并读回核对。浏览器“保存”只存本机。三份蓝牙绑定、一次连接一台；新增配对替换最早绑定。

本版使用无损紧凑模板和独立双副本，空间不足时拒绝新录入并保留已确认样例。旧模板整理只通过明确 USB 命令触发，不在开机自动迁移，也不改变原样例或轮转位置。213 项宿主测试、2,722 步 JS–C 对拍及 3 项变异检查通过；本人录入/导航、21 条样本受控重启保留和整理前后系数一致已有本轮证据。这不是所有人、所有噪声环境或完整七词矩阵的准确率保证。
