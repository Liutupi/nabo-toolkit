适用 ESP32-C3、8 MiB、无 PSRAM 的 AI Passport。已有工牌要保留原分区、名片、快捷键、绑定和样例，请使用受保护 app-only 升级，先识别实际设备/容量/分区；不要默认 flash、刷合并镜像或整片擦除。

2. 按键和配对
面向屏幕，右侧由上到下是“上、下、OK”，OK 在最底部；长按约 0.5 秒，松开不追加短按。欢迎约 5.5 秒完整播完后进菜单，任意键可跳过。上下选择，OK 进入，长上返回。
在“连接”选新增配对，在手机/电脑蓝牙里选择“NABO 工具箱”，按系统要求输入配对码或核对两端数字；数字比较需要手机和工牌两端都确认。选择正确设备类型，等就绪后使用。三份绑定、一次连接一台；新绑定替换最早一份，旧设备之后可能要重配。

3. 本人离线语音：先录入，再查找
主菜单长按底部 OK 进入“语音查找”。七个固定目标是读书、抖音、音乐、名片、拍照、截图、语音输入。
• 上下选择要录入的目标，长 OK 开始一条录入。先安静约 300 毫秒，等“请说目标名称”后自然说一次卡片名称，不加“打开”或“NABO”。等“已保存”和计数增加，再录下一条；每词录三条。
• 已有旧六词样例会保留，不需要为新词重录旧词。满三条后再次长 OK 会尝试替换该词最早样例；保存失败先停止重试。容量与配置/绑定共享，最长和最宽的模板不保证无限覆盖。
• 短 OK 识别全部已录目标，当前高亮只决定录入哪个词。成功只进入工具，不发送 HID；Typeless/语音输入须进组后再按原键。个人配置缺少“微信读书”“截图”“Typeless/语音输入”组时会提示，不自动建组。
• 歧义、未知、过长或采音失败不会跳页；长上可取消回菜单。录入有效语音最多 0.96 秒，查询最多 1.92 秒，总窗口最多 3 秒；一次只说一个短词，准备时别说话，说完停顿。音乐、人声和衣物摩擦会干扰，不保证理解否定句或拒绝录音回放。
这是本人声学模板，不持续唤醒、不联网，不保存/上传原始音频；公开固件没有个人模板，其他人需自行录入。

4. 六大工具
• 快捷键：上/下/OK 发送当前三个动作；亮屏长 OK/长下换下一组/上一组。默认截图=截图/Esc/粘贴，Typeless=翻译/提问/语音输入，剪映=分割/撤销/播放，微信读书=上/下/右方向，编辑=撤销/全选/复制。软件快捷键、焦点和翻页行为须匹配。
• PPT：上/下翻页、OK 黑屏；长 OK 开始、长下结束；计时和页数是工牌本地记录。
• 会议：摄像头/举手/静音，长 OK 换模板；桌面应用需匹配快捷键。
• 媒体：先选音乐/抖音，OK 进入时不发 HID。音乐控制音量/播放，亮屏长 OK/长下切下一首/上一首；抖音上/下/右，长 OK/长下没有工具动作。长上先回媒体选择，再回菜单。
• 拍照：先打开支持音量键快门的相机，上键选 0/3/10 秒，下键五连拍，OK 拍照或取消倒计时；在手机检查成片。
• 名片：上下切卡，OK 放大/缩小；大二维码状态长上先退出放大。

5. 息屏遥控和电脑配置
设置里的息屏遥控默认开；已连接的快捷键/媒体工具进入或亮屏后约 30 秒熄屏，短键不续时，暗屏短键仍发。暗屏长 OK 只亮屏并消费，不换组/切歌或追加短 OK；亮屏长 OK 保留原功能。长上返回并亮屏；菜单和媒体选择保持亮屏。
配置页：https://liutupi.github.io/nabo-toolkit/
桌面 Chrome/Edge + USB，先关闭串口监控，连接并选择正确端口，先“从工牌读取”，再编辑、明确写入、读回核对。打开串口可能重启工牌。支持 1–6 组/每组三动作、1–3 张名片；文本宏最多 64 个 ASCII 字符/换行，二维码最多 160 个 UTF-8 字节。Mac/iPhone 与 Windows/Android 绑定分开。浏览器“保存”只保存到浏览器。
要恢复五组默认但保留实际名片，先读回，再选“使用新版默认快捷键（保留名片）”，检查后明确写入。导出的 Wi-Fi 二维码/配置可能有明文密码，不要公开。

6. 旧模板整理与验收边界
旧模板不会在开机自动批迁。需要整理存储时，先关闭采音和配置事务；仅在菜单/语音页，通过明确 USB 命令 >tk.voice.compact 发起。它原样保留样例、所有系数、数量和 next；新副本实际读回并逐项对比后才退休该词旧记录。失败先停止，不擦库、不连续重试；已紧凑词会跳过。
