一、安装方式先选对
本社区“安装”入口使用完整首装镜像，从0x0写入，会覆盖分区表和NVS，重置原设置/蓝牙绑定。完整首装路径尚未真机验收。若需要保留已有分区、设置、绑定和素材，请使用GitHub Release里的app-only保护升级方式，不要点社区一键安装。仅适用于ESP32-C3、8MiB Flash的AI Passport。
安装说明与下载：https://github.com/Liutupi/nabo-toolkit/releases/tag/v0.3.0-f3-dev3

二、第一次蓝牙配对
1. 开机等待约5.5秒欢迎动画结束，或按任意键跳过。菜单上/下移动，OK进入。
2. 进入“连接”，选择空槽或“配对新设备”，按OK开放配对窗口。
3. 电脑/手机蓝牙设置中选择“NABO 工具箱”。按两端提示输入或比较配对码；比较数字时确认一致，并在需要时短按工牌OK、在手机确认。
4. 配对完成后选择真实设备类型：Mac、Windows、iPhone/iPad或安卓，按OK。顶部显示就绪后再开始遥控。
5. 连接不上时，先断开其他已经连着NABO的宿主；一次只连接一台。最多存3份绑定，新配对成功会替换最早绑定，不必每次清空NVS。

三、工具按键
通用：在工具页长按上键约0.5秒返回菜单；二维码已放大时先退出放大。长按只触发一次，不使用双击。
• 快捷键：上/OK/下执行当前组动作，长OK下一组，长下上一组。初次在记事本等空白测试区核对，再用于工作软件。Typeless用户先在电脑安装并设置自己的快捷键，再通过配置页匹配。
• PPT：上/下为上一页/下一页，OK黑屏或恢复，长OK开始放映，长下结束放映。本地计时/计数不等于读取PPT状态。
• 会议：OK静音切换，上摄像头切换，下举手，长OK切换软件模板。仅电脑，具体键位需和会议软件一致；无对应快捷键会提示。
• 媒体：上/下音量，OK播放/暂停，长OK下一曲，长下上一曲。
• 拍照：先打开手机相机并确认支持音量键拍照；上切不延时/3秒/10秒，OK拍摄，倒计时期间再按OK取消；下为五连拍。实际是否成片以手机为准。
• 名片：上/下换卡，OK放大/收起二维码。二维码最多160个UTF-8字节；长网址可自行改用短链接。

四、配置快捷键和名片
打开 https://liutupi.github.io/nabo-toolkit/ ，也可下载离线包并解压后打开config.html。
1. 使用电脑Chrome或Edge、USB数据线接工牌；先关闭串口监视器等占用程序。
2. 点“连接工牌”，在浏览器选择工牌自己的USB串口，先点“从工牌读回”。打开串口可能触发重启，需要时重新连接。
3. 顶部选Mac/iPhone或Windows/安卓。快捷键可录入组合键，也可点“手动”设置；系统截获的组合键用手动录入。每组3键，最多6组，文字宏只支持最多64个ASCII字符/换行。
4. 点顶部“名片 / Wi-Fi 二维码”，编辑1–3张名片。需要Wi-Fi码时展开“生成Wi-Fi二维码”，填网络名/密码，点“填入”。手机扫码连接网络，工牌不联网。
5. 点“写入工牌并核对”，等页面提示保存且读回一致。配置保存在工牌，断电后保留。只点“保存到浏览器”不会改工牌。
6. 可导出/导入配置备份；包含Wi-Fi密码的文件不要公开分享。传输中断时重新连接、先读回核对，不要反复盲写。

五、设置与兼容提示
可开关按键提示音/开机语音，修改演讲时长、自动休眠。会议应用、播放器、手机相机需正确获得焦点/权限并匹配快捷键；工牌只发送HID，不知道目标软件的实际状态。最终镜像的全部宿主、三槽切换/长稳/睡眠及完整首装仍未完成验收，电视和阅读器暂未验收，三秒回连目标未通过。请先在自己的环境小范围核对。
