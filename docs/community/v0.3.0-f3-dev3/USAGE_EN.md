1. Choose installation mode first. Community install writes the complete image at0x0, replacing the partition table/NVS/settings/bonds; the full-install path is not device-tested. For preserving an existing layout/data, use the guarded app-only upgrade from the GitHub Release. ESP32-C3/8MiB AI Passport only.
2. Let the welcome finish or press any key. Up/Down selects a menu item; OK enters. Long Up returns from tools; if a QR is enlarged, it exits zoom first. Long press is about0.5s.
3. In Connection, select an empty slot or Pair new device. Choose NABO 工具箱 in the host Bluetooth settings, follow the passkey/comparison prompts, confirm matching numbers on both sides when required, and choose the real host type. Disconnect competing hosts first. Three stored bonds, one active host; new pair replaces the oldest bond.
4. Shortcuts: Up/OK/Down sends current actions; long OK/Down selects next/previous group. PPT: Up/Down changes page, OK toggles black screen, long OK starts, long Down ends. Meeting: OK mute, Up camera, Down hand, long OK changes template; desktop only. Media: Up/Down volume, OK play/pause, long OK/Down next/previous track. Camera: open the phone camera first, Up selects0/3/10s delay, OK triggers/cancels countdown, Down sends five shots through volume-up. Cards: Up/Down changes card; OK toggles zoom.
5. Configuration: https://liutupi.github.io/nabo-toolkit/ . Use desktop Chrome/Edge and a USB data cable. Close serial monitors, connect/select the correct port, read current configuration, edit, then Write and verify. Opening serial may restart the device. Only a matching readback confirms the saved configuration. Browser Save is local only.
6. Configure1–6 groups,3 actions each, and1–3 cards. Key combinations have Mac/iPhone and Windows/Android families. Use manual entry for OS-intercepted shortcuts. Text macros support printable ASCII/newlines up to64 characters. QR payloads are limited to160 UTF-8 bytes. Wi-Fi passwords stay in the QR/export; do not publicly share private exports.
7. Test host shortcuts in a blank scratch area. Apps must support the configured HID shortcuts. The badge cannot confirm real application state or saved photos. Final-image compatibility, long stability, three-slot stress, full installation, TV/reader and the3s reconnect target remain incomplete.
