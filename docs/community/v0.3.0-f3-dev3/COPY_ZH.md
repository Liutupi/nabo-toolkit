NABO 工具箱，把 AI Passport 变成随身蓝牙遥控器。

讲PPT时翻一页，开会时切一下静音，听歌时调音量，合照时隔空按快门——把常用操作交给上、下、OK三颗按键。NABO会换上对应工具的服装，陪你从办公切换到生活；还有完整欢迎动画、专用开机语音和按键提示音。

【六大工具，怎么用】

1. 快捷键｜把最常按的组合键装进口袋
内置常用、Typeless、窗口、剪映、PS、浏览器六组作者默认键位。截图、复制、粘贴、切换窗口等动作，一按发送。通过配套网页可改为自己的1–6组，每组上/OK/下三个动作，支持组合键、多媒体键、最多64字符的英文/数字/符号及换行文字宏。Mac/iPhone与Windows/安卓两类键位分别设置，可区分左右修饰键。Typeless只是触发你电脑中已安装软件的快捷键，工牌本身不录音、不运行Typeless。

2. PPT｜翻页笔 + 本地演讲计时
上/下翻页、OK切换黑屏，长OK开始放映，长下结束放映；工牌显示本地演讲时间与翻页计数。HID只发送按键，不读取电脑实际页码。PPT/Keynote和系统快捷键需按实际环境核对。

3. 会议｜常用会议操作集中到三颗键
OK发送静音切换，上键发送摄像头切换，下键发送举手；长OK切换腾讯会议、飞书、Zoom、Teams模板。有的模板没有举手快捷键，会给出提示。仅用于电脑端，需与应用快捷键设置一致；显示“已发送”不代表读到了真实静音状态。

4. 媒体｜听歌不必总找播放器
上/下调音量，OK播放/暂停；长OK下一曲，长下上一曲。实际响应取决于当前系统与播放器。

5. 拍照｜延时快门和五连拍
先打开手机相机。上键切换不延时/3秒/10秒，OK拍摄或取消倒计时，下键触发五连拍。通过蓝牙“音量+”触发快门，需相机支持该行为；屏幕计数记录发送次数，不确认照片是否保存。

6. 名片｜把常用二维码随身带着
可保存1–3张名片，修改标题、名字、说明和二维码内容；支持网址、文字，以及页面生成的Wi-Fi二维码。上/下换卡，OK放大二维码。手机扫Wi-Fi码加入网络，工牌自身不连接Wi-Fi。单张二维码最多160个UTF-8字节，Wi-Fi密码包含在二维码和导出配置中。

电脑Chrome/Edge + USB数据线：连接工牌 → 从工牌读回 → 编辑快捷键或名片 → 写入工牌并核对。核对一致才表示保存成功，配置断电保留。只点“保存到浏览器”不会修改工牌。也提供离线配置包；页面没有配置上传或统计服务。

【连接与个性化】
最多保存3台蓝牙绑定，一次连接一台；新配对成功后替换最早绑定。支持选择Mac、Windows、iPhone/iPad或安卓设备类型。设置里可开关开机语音和按键音，调整演讲时长及自动休眠。欢迎动画约5.5秒自动进入菜单，也可按任意键跳过。

这是v0.3.0-f3-dev3公开测试版。ESP-IDF6.0.2、ESP32-C3、8MiB、无PSRAM。100项宿主测试与1,710步JS–C对拍通过；最终app的完整欢迎、各工具动画、开机音和无爆破按键音获用户实测确认。之前版本已实测Windows配对/粘贴/音量，以及自定义文字/名片扫码/保存后断电保留；这些未全部在最终dev3重复验收。最终app的240次已连接采样内存达标、音频错误与崩溃均0。

【安装前必读】
社区一键安装使用完整首装镜像，从0x0写入，会覆盖分区表及NVS，重置原有设置和蓝牙绑定。完整首装镜像已通过构建/布局/内容校验，内含同一已验收app；完整首装路径尚未做真机验收。需要保留现有分区、设置、绑定或素材时，请勿使用社区一键安装，改用GitHub的app-only保护升级脚本，先核对设备/容量/分区。安装前自行备份重要数据。
