# 本人离线口令用法（v0.3.2-voice-dev4实验测试版）

这是本人录入的七个固定短口令，用来进入工具页面：**读书、抖音、音乐、名片、拍照、截图、语音输入**。它不是通用语音转文字，也不用于身份验证。只有按键启动时采音，不持续监听，不联网、不上传录音。dev4已通过本轮语音、无损整理和受控重启留存检查；初轮重启的最终根因、多用户/噪声和长稳仍未完全确认。实际范围见[HANDOFF](HANDOFF.md)和[VALIDATION](VALIDATION.zh_CN.md)，不把单次通过扩大为全部场景准确率。

右侧实体键从上到下为 **↑、↓、OK**，OK在最下方。在主菜单长按OK进入“语音查找”。普通工具的按键、暗屏长OK只亮屏等行为不变。

## 先录入本人声音

1. 在安静环境、工牌实际佩戴位置，用↑↓选中一个目标。
2. 长按底部OK一次。先保持安静，等“准备采音”变成“请说目标名称”后，自然说一次卡片上的名称，例如“读书”或“语音输入”。不用加“打开”或“NABO”。
3. 等“已保存”和次数增加，再长OK录下一次。同一目标录三次，显示`3/3`；七个目标分别录入。已有旧六词录入记录会保留，不需要全部重录；新增“语音输入”单独录入即可。
4. 同一词满三次后再长OK，会尝试替换该词最早的一条模板。每次保存后实际读回该词，内容匹配才显示成功并安装到RAM；无法核实时显示失败/未知，不盲目回写或擦库。错误返回不代表旧Flash一定原样保留，真实Flash故障或断电后需再核对。

dev3候选用无损紧凑记录和每词双副本保存：先确认新副本，再退休同词旧副本；旧六词格式仍可直接读取。写前发现空间不足时，拒绝本次录入并保留已确认样例。可用空间还要与个人配置、绑定共享，不能保证每种最长口令都能无限重录；显示保存失败时先停止重试。

准备背景约300ms，整个采音窗口最长3秒；录入模板的有效语音最多0.96秒，识别查询最多1.92秒。慢读、长句或连续说多个词可能显示“口令太长”，这次不保存、不导航。每次只说一次短口令，说完停顿即可；“语音输入”为四字口令，也受录入上限约束，实际自然语速可用性需要真机核对。

## 再识别进入页面

在语音页短按OK，等“请说口令”后说一个已录入词。短OK会匹配全部已录入目标，当前高亮卡片只用于选择录入目标。成功后进入对应页，**不自动发出截图、拍照、播放或其他HID动作**；进入后按原工具键操作。

“读书”进入个人快捷键中的“微信读书”组，“截图”进入“截图”组。**“语音输入”只进入“Typeless”或“语音输入”分组，之后再按原键操作，不自动开启电脑录音，也不自动发送语音输入快捷键。**个人配置中不存在相应组时显示“未找到分组”，不会自动修改或创建组。“抖音”和“音乐”分别进入媒体的对应模式；名片和拍照进入原页面。

未识别、歧义、口令太长、采音失败或操作失败时不会导航；短按OK可以再试。采音中不能切换目标或重复开始，长按↑可取消并回菜单。准备阶段请勿说话，播放音乐、电视、人声、衣物摩擦和自己的提示音都可能影响采音；此模板匹配不理解否定句，也不能保证拒绝一段录音回放。

## 保存和验收边界

工牌只保存声学模板，不保存/导出原始音频。新模板记录与名片/快捷键、设置、蓝牙绑定分开；不需要擦NVS或修改分区。个人模板不包含在公开固件包里，其他人首次使用需自行录入。

宿主模拟和构建只能检查算法、状态、边界和资源装入；本人实际识别、环境拒识、取消、断电保留、BLE共存、内存峰值和功耗仍需分别真机验证。不能把识别分数显示成未经校准的“准确率”，也不能把一位用户的通过扩大成所有人或所有环境可用。
