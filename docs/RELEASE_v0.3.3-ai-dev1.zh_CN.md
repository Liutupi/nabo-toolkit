# NABO 工具箱 v0.3.3-ai-dev1

本实验候选新增默认「AI助手」快捷键组，排在 Typeless 前面：上键发送 F13 对应 Codex，下键 F14 对应 Claude，OK 发送 F15 对应 Grok Bot。工牌发送的是键盘按键；电脑需要安装并运行 [NABO 桥接程序](../desktop-bridge/README.zh_CN.md)。确认聊天框有光标后，长按 OK 切到 Typeless，手动触发自己的语音输入键；长按下键返回 AI助手。暗屏时第一次长按 OK 只亮屏，不切组。

固件 ZIP 的 `desktop-bridge/` 包含桥接源码和中英文配置说明，同时附带离线配置页；不包含账户、个人配置、已编译电脑程序或设备数据。

升级不会自动替换已保存的快捷键和名片。先在新版配置页读回工牌，再显式添加 AI助手；已有六组时需自行调整。原五组、NABO 美术、离线语音查找及其他工具保留。

新应用已安装并校验；保留个人配置的情况下，用户确认 Mac 上三个助手呼出、一次 Typeless 输入及返回切组均正常。全新安装的默认组有宿主覆盖，但未在重置工牌上单独实测。Windows 桥接尚未运行或实测；自动聚焦取决于目标应用的无障碍支持。
