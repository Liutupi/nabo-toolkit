# 给 Grok 的图生视频提示词

在 Codex 的起始图定稿（`art/start/` 里有 S0、S0R、S1–S5）之后再开始。镜头清单和用途见 [ART_BRIEF.md](ART_BRIEF.md) 第 5 节。

## 通用设置

- **首帧**：对应的起始图。循环镜头同时把它锁为**尾帧**。
- **规格**：720×720，24 fps，3 秒（单次动作可以 2–4 秒）。
- **交付**：原片放进 `art/video/batch1/`（第 1 批）或 `art/video/batch2/`（第 2 批），文件名用下面每条写的名字。重拍依次加 `_v2`、`_v3`，**旧片不要删、不要覆盖**。原片不要缩放、改帧率、抠图。
- 每条提示词 = 下面的**通用开头** + 对应的**服装句** + 该条的**动作**和**避免**。

### 通用开头（每条都要放在最前面）

```
固定正面镜头，NABO 正面半身，和首帧完全一致：同一张脸、细圆框眼镜、蓬松棕发、白帽和正向的 NABO 心跳线帽标，人物大小和位置、画面底边切在腰部、纯绿色背景全程不变。干净的 2D 卡通，平涂加两阶赛璐珞阴影，深色描边。
```

### 服装句（按起始图选一句；定稿后如果衣服有变化，按定稿改写）

| 起始图 | 服装句 |
|---|---|
| S0 | 穿白大褂，脖子上挂听诊器。 |
| S0R | 穿白大褂，脖子上挂听诊器，右手在胸前拿着一个白色的大遥控器，遥控器上只有几颗圆按钮、没有文字。 |
| S1 | 穿深色西装外套和浅色衬衫，右手拿一支黑色细长翻页笔。 |
| S2 | 头戴单边耳麦，麦克风杆在嘴边一侧，穿休闲上衣。 |
| S3 | 耳朵上戴大耳罩耳机，穿印花 T 恤。 |
| S4 | 脖子上挂相机背带，双手在胸前托着一台小相机。 |
| S5 | 穿工装衬衫，胸前口袋插着一支螺丝刀。 |

### 通用避免（每条都要放在最后）

```
避免：改变脸型、镜框、发型、帽子或帽标；帽标文字反向或左右镜像；换装或衣服变色；多出手指、手指融合、断腕、道具变形或凭空出现消失；手或道具出画、举过帽顶；镜头推拉、平移、转动、切镜；背景出现阴影、地面、渐变或其他颜色；说话口型、字幕、转场、特效。
```

## 交回之后

把原片放进对应批次目录，告诉 Claude。Claude 会：

1. 每条完整解码，出 0.25 秒间隔的接触表，逐段查身份、镜像、手指和道具；
2. 把审查结果写进 `art/qa/`，标出可用的时间段，需要重拍的给出修订提示词；
3. 抠绿、对齐、抽帧、限色，接进 `prototype/`，你在原型里看效果。
