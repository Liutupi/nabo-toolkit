# NABO 工具箱 · 设计

版本 0.1（M0）· 2026-10-27

一句话：**离线的蓝牙遥控工牌**。工牌模拟一个蓝牙键盘（BLE HID），用上 / 下 / OK 三个键控制电脑、手机、平板；另外能在屏幕上展示名片和 Wi-Fi 二维码。全程不联网。

规则的标准答案是浏览器原型 `prototype/tk_core.js`。改规则先改原型，再改固件。

## 1. 范围

### 首批 6 个工具

| # | 工具 | 一句话 | 发送什么 |
|---|---|---|---|
| 1 | **快捷键** | 六组默认：截图（截屏 / 粘贴 / Esc取消）、Typeless、剪映、微信读书、抖音、编辑；可按自己的习惯修改 | 键盘、多媒体键、文字 |
| 2 | PPT 翻页笔 | 翻页、黑屏、放映，屏幕上显示演讲计时 | 键盘 |
| 3 | 会议键 | 静音、摄像头、举手（腾讯会议 / 飞书 / Zoom / Teams） | 键盘 |
| 4 | 媒体遥控 | 音量、播放暂停、切歌 | 多媒体键 |
| 5 | 拍照快门 | 手机拍照，可延时、连拍 | 多媒体键（音量 +） |
| 6 | 名片 | 名片二维码、Wi-Fi 二维码，最多 3 张 | 不发送，只显示 |

菜单按这个顺序排，快捷键放第一个。

另有两个系统页：**连接**（3 台设备切换、配对）和 **设置**；以及电脑上的**网页配置页**（第 5.7 节）。

### 不做

- 联网功能（Wi-Fi、Home Assistant、Webhook）。底座不带 Wi-Fi。
- 红外遥控（没有红外管）。
- 读回电脑状态。HID 只能单向发送，屏幕上只写“已发送”，不写“已静音”。
- 存密码。文字宏只建议存邮箱、地址、常用回复。
- 输入中文。文字宏只发 ASCII（HID 键码没有中文，靠输入法会出错）。

## 2. 底座

- 从《游戏特辑》nabo-games v1.0.0 独立离线底座分出（和冒险之旅同一做法），删掉跳一跳、深潜，保留直绘渲染器、字库、提示音、按键队列、NVS、深睡。
- 打开 NimBLE，只做外设（peripheral），配置参考小智电台版 `ai-passport-nabo` 板型的 `config.json`（MAX_CONNECTIONS=1，MAX_BONDS 改为 3，NVS_PERSIST）。
- HID 报告描述符、键码表从电台版 `nabo_keys.c` / `nabo_keys_model.c` 移植：报告 1 = 8 字节键盘，报告 2 = 16 位多媒体键。不同的是这里工具箱是 NimBLE 唯一的使用者。
- 分区表不变（app 0x3f0000、assets 3 MB、files 1 MB），板型身份不变，能用 upgrade 和牌桌版、冒险版互相切换。NVS 用新命名空间 `nabo_tk`，不碰旧键。

## 3. 按键

按键事件：**短按**（按下后 500 ms 内松开，松开时触发）和**长按**（按住满 500 ms 时触发，松开不再触发）。不用双击，免得等双击超时带来延迟。

全局规则：**长按上 = 返回**（工具页回菜单，子页回上一级）。所以工具里长按上永远不是工具键。

| 画面 | 上 | 下 | OK | 长按 OK | 长按下 |
|---|---|---|---|---|---|
| 菜单 | 上一个 | 下一个 | 进入 | — | — |
| PPT 翻页笔 | 上一页 | 下一页 | 黑屏 / 恢复 | 开始放映 | 结束放映 |
| 会议键 | 摄像头 | 举手 | **静音** | 换会议软件 | — |
| 媒体遥控 | 音量 + | 音量 − | 播放 / 暂停 | 下一曲 | 上一曲 |
| 拍照快门 | 换延时（0 / 3 / 10 秒） | 连拍 5 张 | 拍照（倒数中再按 = 取消） | — | — |
| 快捷键 | 本组上键 | 本组下键 | 本组 OK 键 | 下一组 | 上一组 |
| 名片 | 上一张 | 下一张 | 放大二维码 / 还原 | — | — |
| 连接 | 上移 | 下移 | 连这台 / 开始配对 | 改设备类型 | 删除配对（再按 OK 确认） |
| 设置 | 上移 | 下移 | 改这一项 | — | — |

开机画面：任意键跳过，直接进菜单，跳过这一下不会发给电脑。

最常用的动作都放在单击上：粘贴、复制、截屏、翻页、静音、播放、拍照。快捷键页记住上次用的那一组。

## 4. 连接

- 存 **3 台设备**（槽 1–3），每台记住名字和**设备类型**：Mac / Windows / iPhone·iPad / 安卓。快捷键按当前设备类型换算（Ctrl ↔ Cmd 等）。
- 同一时间只连一台。在“连接”页选另一台，工牌断开当前设备，只对那一台发定向广播重连。
- 配对：选“配对新设备”，广播 60 秒，设备名“NABO 工具箱”。配对成功后马上让用户选设备类型。保留最近新增的 3 份绑定，满额时新配对自动替换最早绑定的设备，不要求先手动删除，也不逐次确认这一正常替换行为。仅打开窗口、取消或超时不移除旧绑定；普通回连不改变绑定先后顺序（FIFO，不是按最近使用淘汰）。手动删除仍可用。
- iReader Tango 2S 和办公室小米电视是补充兼容目标，分别按具体系统/型号验证 HID 和按键；不凭产品类别推定已通过。当前 F0 只实现粘贴/音量探路，不声称已有阅读器翻页或电视完整遥控。
- 未连接时在工具里按键：不发送，提示“未连接 · 去菜单选「连接」”（红色，1.5 秒）。
- 顶栏右边一直显示连接状态：已连接显示设备名，未连接显示“未连接”，配对中显示倒数。

## 5. 各工具细节

### 5.0 开机画面和开机语音

和之前的 AI Passport 项目（算命机、声音实验室）一样：开机先放一段开机画面，带一句 NABO 的开机语音。休眠唤醒后也从开机画面开始。开机画面也用作社区投稿的封面。

时间从进入开机画面算起（**E** = 程序动画，**X** = Codex 静态素材，**G** = Grok 视频片段）：

| 时间 | 画面 | 谁做 |
|---|---|---|
| 0–400 ms | 屏幕中心一个小圆点亮起，向外扩出三圈蓝牙信号波纹（连接青） | E |
| 400–1000 ms | 8 个工具图标沿一个圆依次弹出，每个间隔 60 ms，带一点回弹，像被遥控点亮 | E + X（图标） |
| 700–1400 ms | 标题字标“NABO 工具箱”从上方落下，副标题“陪你遥控万物”淡入 | E + X（字标） |
| 1.4 s 起 | NABO 从屏幕底部升起（300 ms 缓出），接着播欢迎动作：举起遥控器朝镜头一按，按下那一帧 8 个图标同时闪一下，然后挥手 | E + G `tk00_welcome` |
| 1.4 s 起 | 开机语音 **“那波，陪你遥控万物！”**，播放时其他提示音压到四分之一 | 音频 |
| 约 5.5 s | 完整播放约 4.04 秒的欢迎动作后，自动进菜单（用户已选完整播放） | E |

- 任意键跳过，直接进菜单。
- 蓝牙在开机画面期间就开始重连上次的设备，不等动画播完。
- 设置里可以关掉开机语音（画面照放）。

开机语音规格（做法和算命机、声音实验室一致，见 `audio/VOICE.md`）：

- 生成：即梦 Dreamina Canvas TTS，音色“阳光小男孩”，文本 `那波，陪你遥控万物！`。故意写“那波”而不是“NABO”，TTS 才会读对。**只生成一次**，不要重复付费生成。
- 处理：`highpass=f=90,lowpass=f=6500,loudnorm=I=-16:TP=-3:LRA=7,afade=t=in:d=0.01`，转成 PCM s16le 单声道 16 kHz，存为 `audio/boot-welcome.wav`。原片放 `audio/originals/`，来源和参数记在 `audio/generation.json`。
- 固件：编进 app，约 2.5 秒 × 32 KB/s ≈ 80 KB。进入开机画面 1400 ms 后开始播，按 skill 的音频规则走 16 kHz I2S，不满幅输出。

### 5.1 PPT 翻页笔

- 上一页 / 下一页发 PageUp / PageDown（PowerPoint、WPS、Keynote、PDF、Google 幻灯片都认）。黑屏发 `B`。
- 开始放映：Windows `F5`；Mac（PowerPoint）`Cmd+Shift+Enter`。结束放映：`Esc`。
- 屏幕：大号计时 `mm:ss`、本地页码（下一页 +1，上一页 −1，最小 1）、时长进度条。
- 计时从“开始放映”或第一次翻页开始，“结束放映”停止。演讲时长在设置里选（5–60 分钟，默认 10）。最后 2 分钟进度条变橙并提示“还剩 2 分钟”，超时变红并显示“超时 +m:ss”。演讲时不发提示音。
- 页码只是工牌自己数的，不是幻灯片真实页码，界面上写“已翻 n 页”。

### 5.2 会议键

快捷键表（**全部待真机实测**，固件里做成数据表，以后能改）：

| 软件 | 系统 | 静音（OK） | 摄像头（上） | 举手（下） |
|---|---|---|---|---|
| 腾讯会议 | Win | Alt+M | Alt+V | 无快捷键 |
| 腾讯会议 | Mac | Cmd+Shift+M | Cmd+Shift+V | 无快捷键 |
| 飞书 | Win | Ctrl+Shift+D | Ctrl+Shift+V | 无快捷键 |
| 飞书 | Mac | Cmd+Shift+D | Cmd+Shift+V | 无快捷键 |
| Zoom | Win | Alt+A | Alt+V | Alt+Y |
| Zoom | Mac | Cmd+Shift+A | Cmd+Shift+V | Option+Y |
| Teams | Win | Ctrl+Shift+M | Ctrl+Shift+O | Ctrl+Shift+K |
| Teams | Mac | Cmd+Shift+M | Cmd+Shift+O | Cmd+Shift+K |

- 没有快捷键的动作，按了提示“这个软件没有举手快捷键”，不发送。
- 设备类型是手机或平板时，整页提示“会议快捷键只支持电脑”。
- 页面上注明：会议窗口要在最前面（Zoom 可以在它的设置里开“全局快捷键”）。

### 5.3 媒体遥控

多媒体键：播放暂停 0xCD、下一曲 0xB5、上一曲 0xB6、音量 + 0xE9、音量 − 0xEA。电脑、手机、平板、安卓电视都认。

### 5.4 拍照快门

- 发多媒体键“音量 +”，iPhone 和安卓相机都把它当快门。相机没打开时只会调音量。
- 延时 0 / 3 / 10 秒，倒数时屏幕显示大数字，每秒响一声“嘀”，最后一声高音。
- 连拍：每隔 600 ms 发一次，共 5 张。连拍不用延时。
- 倒数中再按 OK 取消。

### 5.5 快捷键

- 最多 6 组，每组 3 个键（上 / OK / 下）。每个键可以是：组合键（任意修饰键，分左右，加一个键）、多媒体键、文字（≤ 64 个 ASCII 字符，逐字发送）。
- 组合键按“设备类型”分两套：Mac / iPhone 一套，Windows / 安卓一套。当前连的设备是哪类就发哪套。
- **默认表按作者2026-10-28的明确要求更新**：删除窗口、PS、浏览器，增加微信读书、抖音与编辑，并给截图组增加Esc取消。Typeless和剪映原映射保留；其他人可通过配置页改为自己的习惯（第 5.7 节）。已有工牌或浏览器中保存的个人配置不会因新默认表自动覆盖。

| 组 | 上 | OK | 下 | Mac | Windows |
|---|---|---|---|---|---|
| 截图 | 截屏 | 粘贴 | 取消 Esc | Ctrl+Cmd+Shift+4（区域截图到剪贴板）/ Cmd+V / Esc | Win+Shift+S / Ctrl+V / Esc |
| Typeless | 翻译 | 语音输入 | 随便问 | 右Option+右Shift / 右Option+M / 右Option+Space | 右Alt+右Shift / 右Alt / 右Alt+Space |
| 剪映 | 分割 | 播放 / 暂停 | 撤销 | Cmd+B / Space / Cmd+Z | Ctrl+B / Space / Ctrl+Z |
| 微信读书 | 上一页 | 下一章 → | 下一页 | ↑ / → / ↓（无修饰键） | ↑ / → / ↓（无修饰键） |
| 抖音 | 上个视频 | 向右/快进 | 下个视频 | ↑ / → / ↓（无修饰键） | ↑ / → / ↓（无修饰键） |
| 编辑 | 撤销 | 复制 | 全选 | Cmd+Z / Cmd+C / Cmd+A | Ctrl+Z / Ctrl+C / Ctrl+A |

  截屏仍用原“截到剪贴板”映射，截完可直接按粘贴；下键改发Esc用于取消。Typeless 两套仍是作者原绑定（Mac 来自 Typeless 设置截图，Windows 来自电台版快捷键程序）。
- 微信读书/抖音在Mac、Windows、iPhone/iPad、安卓均发送相同的标准键盘↑（usage0x52）、→（0x4f）、↓（0x51），修饰键为0；“右键”指OK发送右方向键，不是新增实体键或鼠标右键。用户希望微信读书的→用于下一章；能否翻页/跳章取决于实际App、页面模式和焦点。抖音的→可能是快进，不能承诺下一视频。用户已确认当前测试端能调出截图并能取消，微信读书/抖音反馈“可以了”；未注明手机还是电脑，只记当前端可用，不代表所有手机/电脑或每个跳章/快进行为逐项通过。当前反馈来自旧dev3更新后的配置，不能当作新候选固件的实机验收。
- 旧dev3仍会优先使用NVS中已保存的组。应用新默认组时，先从工牌读回，再点“使用新版默认快捷键（保留名片）”，最后“写入工牌并核对”；按钮只替换当前页面的groups，保留的是当前页面的cards，不能省略先读回。不要擦NVS或用默认flash来更新快捷键。
- 屏幕：组名、组号（2/6），3 个键各一行，写名字和实际组合键，按下的那行高亮。

### 5.6 名片

- 最多 3 张卡，每张：标题（如“微信”“家里 Wi-Fi”）、名字、一行说明、二维码内容（≤ 160 字节）。
- Wi-Fi 卡的二维码内容是标准格式 `WIFI:T:WPA;S:<名称>;P:<密码>;;`，手机相机扫了直接连。Wi-Fi 密码明文存在工牌里，配置页要写清楚。
- 微信名片：把自己的微信二维码图解析成链接再填进去（配置页可以帮忙解析上传的图片）。
- OK 放大：白底、二维码占满宽度、隐藏 NABO 和底栏，方便扫码。
- 二维码在固件里现算（nayuki QR Code generator，MIT），纠错等级 M。

### 5.7 网页配置页

- 原型：`prototype/config.html`。改好点“保存”，打开着的工牌原型马上换成新键位。
- 正式版：工牌用 USB 线连电脑，用 Chrome 或 Edge 打开同一个页面（可以是本地 HTML 文件，不需要联网），通过 Web Serial 写进工牌 NVS。
- 能改：1–6组快捷键（组名、每个键的名字、类型、组合键）、1–3张名片（含Wi-Fi二维码生成）。会议、PPT、媒体、拍照的键位固定，不在配置页里。新版默认组按钮只替换当前编辑的快捷键、保留当前页面名片，既不自动读设备，也不自动写设备；先读回，再替换，显式写入核对才保存。
- 录键：点键位按钮，在键盘上按一下组合键就录好，能分清左右 Ctrl / Shift / Option / Cmd；只按修饰键的组合（如右Option+右Shift）也能录。系统级组合（Cmd+Shift+4、Win+L）会被系统先拦截，用“手动”勾选。
- 配置是一份 JSON（`v: 1`），上限 4000 字节，可以导出、导入备份。导出文件里如果有 Wi-Fi 密码，分享前要删。

F2统一限制：组名/键名各8个Unicode字符，名片标题6字、名字24字、说明32字，二维码160个UTF-8字节；总规范JSON仍≤4000字节。F2当时仅扩大旧页面6字键名/16字名字的输入限额；本节默认组后来按用户明确要求更新，字段和协议版本仍为v1。平台绑定可清空；文字宏允许可打印ASCII和换行，非法字符拒绝保存，不静默跳过。页面区分浏览器保存与USB写入，写入成功后自动读回核对；协议/验证见CONFIGURATION。新增中文标签使用同源字体的Flash备用字库，按字号缩放。

## 6. 设置

| 项 | 取值 | 默认 |
|---|---|---|
| 按键提示音 | 开 / 关 | 开 |
| 开机语音 | 开 / 关 | 开 |
| 演讲时长 | 5 / 10 / 15 / 20 / 30 / 45 / 60 分钟 | 10 |
| 自动休眠 | 5 / 15 / 30 分钟 / 连接时不休眠 | 连接时不休眠 |
| 关于 | 版本号、蓝牙地址 | — |

自动休眠：演讲和开会时常常很久不按键，所以默认连接中不休眠，未连接时 5 分钟休眠。PPT 计时进行中、拍照倒数中一律不休眠。

## 7. 界面

- 屏幕 240×320 竖屏，RGB565。配色、字号沿用冒险之旅（`nabo-adventure/game-art/adventure/UI_DESIGN.md` 第 1–3 节）：INK 夜蓝 `#182439`、PAPER 纸色 `#EEE6DE`、GOLD `#FFAD84`、RED `#E65152`。中文用思源黑体 18 / 16 / 12，数字用 Archivo Black 28 / 48（48 号要补 `:` `+` 字形，用于计时）。
- 每个工具一个点缀色：PPT 橙、会议绿、媒体紫、拍照蓝、快捷键金、名片粉、连接青、设置灰。
- 版式：
  - 顶栏 y 0–32：左边工具名，右边连接状态。
  - 底栏 y 290–320：按键提示，和第 3 节的表一致。
  - 工具页 NABO 放右下角：原型里是 72 px 圆形头像占位（y 176–248）；正式美术是 110 px 高的半身像，占右下 84×148 的区域，到时按键说明栏收窄。
  - 菜单：顶部 NABO 打招呼条（y 32–104），下面 2 列 × 4 行工具卡（6 个工具 + 连接 + 设置）。
- 每次发送后，工具页底部弹出一条“→ Ctrl+B 分割”提示（1.2 秒），NABO 做一个小反应。
- 原型里的 NABO 是参考图 `nabo-idle.png` 原样裁出来的待机帧（睁眼 / 半闭 / 闭眼，眨眼用），**没有重画**。正式美术见第 8 节。

## 8. NABO 的戏份（M1 美术）

**NABO 不重新设计**，身份锁定在 `nabo-idle.png`，只换行头和道具、做新动画。完整规格、分工（Codex / Grok / Claude）、行头清单和 14 条镜头见 [ART_BRIEF.md](ART_BRIEF.md)；提示词见 [CODEX_PROMPTS.md](CODEX_PROMPTS.md) 和 [GROK_PROMPTS.md](GROK_PROMPTS.md)。

## 9. 技术预算

| 项 | 估计 | 待验证 |
|---|---|---|
| NimBLE 外设 + HID 代码 | Flash 约 250–350 KB | M2 后实测 |
| QR 生成 | Flash 约 15 KB，RAM 约 4 KB（只在名片页） | |
| 开机语音 | Flash 约 80 KB（16 kHz 单声道 PCM） | 生成后实测 |
| 美术 | 放 app 分区（离线底座的素材都编进程序） | M1 后计算 |
| 运行内存 | NimBLE 常驻约 40–60 KB + 渲染约 30 KB | **第一个要实测的风险** |

app 分区 0x3f0000（约 3.94 MB）。冒险之旅 v0.1.0 时这个底座的程序约 1.16 MB；工具箱删掉两个游戏后会更小，开工时用实际镜像重算。

## 10. 风险和先做的验证（M2 之前的蓝牙探路）

1. 离线底座打开 NimBLE 后的空闲堆和最大连续块（目标空闲 ≥ 60 KB）。
2. 3 台设备定向重连：Mac、Windows、iPhone、安卓分别测。
3. iPhone、安卓相机是否都认 BLE 的“音量 +”当快门。
4. 会议快捷键表逐条实测。
5. 连接中长时间不按键的耗电（决定默认休眠策略）。

## 11. 串口诊断（M4）
