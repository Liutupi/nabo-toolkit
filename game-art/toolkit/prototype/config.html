第一次使用：连接、读回、编辑、写入
  1. 用电脑 Chrome 或 Edge 打开此页，用 USB 数据线连接已安装工具箱固件的工牌。
  2. 点“连接工牌”，在浏览器弹窗选择工牌的 USB 串口，再点“从工牌读回”。
  3. 修改快捷键或名片，点“写入工牌并核对”。显示核对一致后，配置已保存在工牌，断电保留。

“保存到浏览器”只保存本机编辑内容。串口被占用时请先关闭串口监视器；工牌重启后可能需要重新连接。Wi-Fi 二维码供手机扫码加入网络，工牌自身不连接 Wi-Fi。此页没有配置上传或统计服务；导出的配置可能含 Wi-Fi 密码，请妥善保管。

给哪类电脑设置：
未连接工牌；当前编辑不会自动写入。

快捷键分组

工牌上长按 OK 换下一组。点键位按钮后，在键盘上按一下组合键就录好了，能分清左右 Option / Shift。 系统级的组合（比如 Mac 的 Cmd+Shift+4、Windows 的 Win+L）会被系统先拦下，浏览器录不到，请点“手动”。
新版分组：截图（含Esc取消）、Typeless、剪映、微信读书、抖音、编辑。请先“从工牌读回”，再点此按钮：它替换当前编辑中的快捷键，保留当前页面的名片；需另点“写入工牌并核对”才会生效。读书/抖音发送↑、→、↓方向键，实际动作由App决定。

名片

1–3 张，二维码内容最多 160 个 UTF-8 字节。工牌上按 OK 放大二维码。

备份

换电脑或者分享给朋友时用。配置文件里有 Wi-Fi 密码的话，分享前先删掉。
