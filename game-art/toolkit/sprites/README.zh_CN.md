# 第 1 批精灵

七条 Grok 原片原样保存在 `../art/video/batch1/`。535 帧全部自动解码；0.25 秒接触表、定稿/首/尾头部对比及绑定原片哈希的人工审片记录在 `../art/qa/batch1/`。审片为 PASS_WITH_NOTES：欢迎遥控器短暂靠近下半脸，会议点头比要求深；抽样中帽标、脸和道具保持可辨认。

在仓库根运行 `tools/review_toolkit_video.py` 和 `tools/build_toolkit_sprites.py`，依赖 Python 3、ffmpeg/ffprobe、Pillow 12.1.0、NumPy 2.4.1。打包器拒绝哈希变化或缺少人工审查的输入，不覆盖原片。抠绿不使用磨平五官的平滑滤镜，先统一整画布变换到 256×256 RGBA，再使用固定半身/头像裁切，不逐帧按包围盒缩放，底边中点为锚点。

欢迎：8 帧、4,042 ms、115×150；六条待机各 12 帧、3,000 ms、84×110；基础待机额外输出 64×64 圆头像。循环去掉重复的三秒闭合帧。每个动作共用 63 个 RGB565 不透明色加透明索引 0；索引前边缘向 `#14203A` 合成。量化绝对通道误差阈值为平均 ≤12、最大 ≤96，逐帧实测在 `manifest.json`。无损解码对比对象是索引目标帧，并非原 RGBA 母版；量化损失单独记录。

8 个 `.tks` 共 **405,362 字节**，低于第一批 1 MiB 预算。全部解码与索引目标逐像素相同（差异为零），每帧有解码内容 CRC。浏览器 atlas 位于 `../prototype/assets/sprites/`，使用同一帧和调色板，已接入原型。C 解码器/固件接入、LCD 色彩/帧率和语音留到 F3；F0 不包含这些素材。

二进制小端格式，版本 `TKSPR1\0\0`：

- 头 `<8s4H2I>`：魔数、宽、高、帧数、调色板数（64）、时长毫秒、循环标记。
- 64 个 RGB565 uint16；索引 0 透明。
- 每帧索引 `<5I>`：时间、绝对负载偏移、负载字节数、解码 CRC32、关键帧标记。
- 负载：`高+1` 个相对负载开头的 uint32 行偏移，然后为行数据。
- token 数量为 `(token & 127)+1`。关键帧高位 1 表示重复后一个索引，0 表示字面索引；差分帧高位 1 表示跳过上一帧相同像素，0 表示变化的字面索引。

解码器检查头部、时间、行表、索引、调色板范围、首关键帧和 CRC；8 项测试含损坏与截断输入。帽标有方向，禁止镜像。
