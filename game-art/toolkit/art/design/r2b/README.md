## 做法

四张均以用户确认的 `art/start/S0_base.png` 为参考，使用内置 imagegen 仅编辑服装、身体和道具。生成的头部不用于交付，最终统一复用 `../r1b/head_locked.png`。S2/S3 的耳部配件来自旧 r2 已提取的实际生成像素，仅按头部从 4.5 倍到 3.0 倍的相似变换重新放置；没有重画头部或新增帽标。

原参考与旧轮次文件保留。头部沿用 r1b 的黑底反预乘边缘处理、3.0 倍缩放和 `(176,30)` 偏移。身体以同一颈部点和腰部底边对齐，帽顶 y=60。四张生成身体都已延伸到底边，无需额外缩放。

重新合成：

```sh
python3 game-art/toolkit/art/design/r2b/assemble_r2b.py
```

## 自查

- 四张均为 1024×1024；背景纯 `#00B140`，透明区域合成后背景错误像素数为 0。
- 不透明头部区域扣除允许添加的耳部配件遮挡后，与已确认 S0 的像素差异为 0。
- 正面帽标区域与嘴部区域与 S0 逐像素一致；帽标没有镜像，话筒不遮嘴中央。
- 头部位置与大小一致；四张主体宽度为 539、543、572、541 px，约占画面 53%–56%；双手与肘部均完整在画内。
- 腰部底边统一到 y=1024，留出挥手/举手的侧向空间；实际动画仍须生成后审片，静态留白不替代动作验证。
- 已目视检查 110 px 半身与 64 px 圆头像在 `#14203A`、`#22324F` 上的可读性，人物、耳机、相机和工装可以辨认。
- 未在本轮量化到 ≤64 色或 RGB565，动画预算、循环、手指/道具连续性和实屏效果由后续处理验证。
