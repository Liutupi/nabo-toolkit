## 方法

沿用第 1 轮已认可的身份锁定方法：原参考左帧不重新设计，只生成头部以下的身体与道具，然后复用原头部层。原参考、r1、r2 及其原始生成结果全部保留。

边缘在 224×224 原图上处理：保持原遮罩向内收缩两像素后的全部 RGB 不变，仅在轮廓带内以相邻内部颜色估计黑底预乘 alpha，再进行颜色除以 alpha 的反预乘。没有画新发丝或修改头部内部像素。结果在纯绿底 4 倍检查并与原遮罩对照；后续抠绿仍应使用保留的 RGBA 母版以减少二次色边。

头部整体等比缩放 **3.0 倍**，偏移 **(176, 30)**；帽顶主体在 **y=60**，脸型、眼镜、帽标比例与方向不变。所有图复用同一头部层。生成的身体锚定同一颈部；S0 身体按颈部锚点统一等比放大约 1.0996 倍，补齐生成器留下的底部绿空隙。头部不参与该变换，身体未单独拉伸某一方向。

## 自查

- 1024×1024 PNG，纯 `#00B140` 背景；所有透明外部像素合成后的背景值一致。
- 人物主体宽度 S0=541 px、S0R=549 px、S1=552 px，约占画面 53%–54%；左右各留约 230 px，肘部与手全部在画内。
- 底边切到腰部，身体完整延续到画面底边，原胸口截断已补全。
- 三张图使用同一个头部层；y=0–493 内不透明头部像素与 S0 的差异为 0，原尺寸内部 RGB 不变的断言通过。
- 帽标没有镜像；S0R 遥控器、S1 翻页笔均在右手，未挡脸和帽标。
- 已目视检查对照图、绿底边缘放大与两种蓝底的小尺寸图。
- 64 px 圆头像保持 NABO 识别；110 px 半身的脸比旧构图小，字标本来就无法在这一尺寸逐字辨认，原帽标未重画。
- 逐帧动作、真正挥手/举手的出框情况仍需 Grok 生成后审片，本轮留白检查不能代替视频验证。
