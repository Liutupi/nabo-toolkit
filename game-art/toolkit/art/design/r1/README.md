## 做法与身份锁定

1. 原参考 `../../reference/nabo-idle.png` 未修改，SHA256 为 `c63575691d15220e8d6fafdab911a10767a5fc1c13925992dbd10e3a5e93d3fa`。使用左侧睁眼帧 `(0, 0, 224, 224)`。
2. S0 直接复用该帧的原始角色像素，仅移除外侧黑背景与孤立的压缩噪点。没有重新生成脸、眼镜、头发、帽子或帽标，也没有添加下半身。原白大褂、听诊器和胸牌保留。
3. S1 服装和翻页笔使用内置 OpenAI imagegen 参考图编辑制作。原始生成结果仍会轻微重绘头部，因此最终合成时丢弃生成头部，固定使用同一份原参考头部。只保留生成的衣服、手与翻页笔。颈部连接处使用短范围融合，面部不参与融合。
4. 原参考统一以 4.5 倍缩放、坐标 `(8, 24)` 放入 1024×1024 画布。三张图沿用同一头部大小和位置，帽顶主体约在 y=69，接近规格 y≈60。保持参考方向，不做镜像。
5. Pillow 仅处理上述像素复用、抠像、构图、指定尺寸、纯色背景和检查图排版，不生成或拼画五官。S0 来源是 224×224，放大母版仍保留原图细节上限，不声称生成了新的高清身份细节。

重新合成和检查：

## 自查

- 三张 PNG 均为 1024×1024，正面半身，底边切过躯干，无腿部或下半身扩展。
- 三张图 y=0–719 的保护区域逐像素对比差异均为 **0**；脸、眼镜、发型、白帽、帽标来自同一原参考。
- 帽标方向与参考一致，未镜像；S1 的翻页笔在角色右手、画面左侧。
- 背景由透明中间件统一合成到纯 `#00B140`；衣服和道具不含绿色设计元素。
- 110 px 半身的宽度约 84 px，适合规格中的右下角区域；64 px 头像直接裁自相同图片。
- 已目视检查两种深蓝背景：眼镜、双眼与帽子可辨认；帽标小字在实际小尺寸下会变软，未重新绘制或修改原标。
- 手和翻页笔保持简单；生成的服装清晰度高于原参考头部，最终小尺寸观感仍需用户确认。
- ≤64 色、RGB565、动画帧数、总包体预算、循环和设备显示检查属于后续抽帧与打包阶段，本轮未做这些转换。
